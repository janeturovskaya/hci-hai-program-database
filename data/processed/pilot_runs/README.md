# Pilot run summaries

Use this folder for human-written summaries of completed pilot runs.

- Do not store full copied web pages or long copyrighted passages.
- Do not store sensitive personal information.
- Summarize what happened in the pilot, including what worked, what was confusing, and what should change before scaling.
- Link to relevant pull requests, commits, issues, or review notes when useful.
- Use `docs/pilot_findings_template.md` as the starting template for each pilot summary.
- Keep structured candidate and canonical data in the CSV files, not in this folder.
