# Pilot batch checklist

Use this short checklist for the first 3–5 university pilot batch.

- [ ] Selected 3–5 universities manually.
- [ ] Collected official source URLs.
- [ ] Copied short evidence snippets only.
- [ ] Added candidates through `scripts/add_candidate.py`.
- [ ] Generated `reports/candidate_review.md`.
- [ ] Checked duplicate warnings.
- [ ] Reviewed evidence quality.
- [ ] Updated candidate statuses to `reviewed` or `rejected`.
- [ ] Promoted only reviewed candidates.
- [ ] Generated canonical evidence rows where appropriate.
- [ ] Ran `python scripts/validate_manual_data.py`.
- [ ] Ran `python scripts/check_placeholder_data.py`.
- [ ] Ran `python -m unittest discover`.
- [ ] Inspected canonical manual CSV output.
- [ ] Recorded schema gaps or workflow friction.
