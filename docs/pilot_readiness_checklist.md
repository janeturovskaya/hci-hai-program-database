# Pilot readiness checklist

Use this checklist before adding real pilot data.

- [ ] Main branch is up to date.
- [ ] CI is passing.
- [ ] Candidate CSVs are clean.
- [ ] Manual CSVs are clean.
- [ ] No placeholder data appears in data files.
- [ ] Source evidence rules reviewed.
- [ ] 3–5 universities selected manually.
- [ ] Official source URLs ready.
- [ ] Snippets are short and claim-specific.
- [ ] Local or Codex cloud commands are ready.
- [ ] Pilot findings template is ready.
